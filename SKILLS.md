## Reversa Skills (`.agents/skills/`)

Documentação completa em [LEGADO.md](LEGADO.md).

O **Reversa** é um framework de engenharia reversa para descobrir, documentar e especificar sistemas legados em artefatos executáveis.

| Skill | Descrição |
|-------|-----------|
| **reversa** | Orquestrador principal do Reversa — análise completa de sistema legado |
| **reversa-agents-help** | Explica com analogias o que cada agente do Reversa faz |
| **reversa-archaeologist** | Análise profunda do código legado módulo a módulo |
| **reversa-architect** | Sintetiza análise em documentação arquitetural (C4, ERD, mapa de integrações) |
| **reversa-arquitetura-3d** | Visualizações 3D interativas de arquitetura com Three.js |
| **reversa-audit** | Auditoria leitora estrita — cross-check entre requirements, roadmap e actions |
| **reversa-autonomous** | Modo autônomo — roda sequência completa de agentes sem paradas |
| **reversa-clarify** | Gera perguntas para resolver pontos ambíguos dos requirements |
| **reversa-coding** | Executa o actions.md em código com checkboxes e progress.jsonl |
| **reversa-curator** | Decide o que migra, descarta ou precisa decisão humana (migração) |
| **reversa-data-master** | Documenta banco de dados — tabelas, relacionamentos, constraints, ERD |
